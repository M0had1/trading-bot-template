Diagnosis
- Relevant log lines show the build script and the missing binary: [line 79](#L79) (build script), [line 80](#L80) (rsbuild used), and the actual error [line 81](#L81) ("rsbuild: not found"). The build then fails with a non-zero exit code [lines 82–88](#L82-L88).

Error type and cause
- Error type: missing build tool / command not found.
- Cause: The package or binary "rsbuild" that the npm script runs ("rsbuild build") is not available on the build machine, so the npm script fails. This usually happens because the package is not installed (not listed in package.json / not committed) or installation of that package failed during dependency install.

Solution (steps to fix)
1. Verify whether rsbuild is declared in package.json
   - Open your repo's package.json and check the scripts/dependencies: https://github.com/M0had1/trading-bot-template/blob/master/package.json
   - If rsbuild is already present, make sure package.json and package-lock.json are committed and pushed.

2. If rsbuild is missing, add it as a dependency (recommended: devDependency)
   - Locally run:
```bash
npm install --save-dev rsbuild
git add package.json package-lock.json
git commit -m "chore: add rsbuild devDependency"
git push
```
   - This ensures Netlify installs rsbuild and the binary becomes available at node_modules/.bin/rsbuild so the "npm run build" script can run.

3. Alternative quick fix: use npx (not recommended as a long-term fix)
   - You can change the build command to use npx so Netlify will fetch and run rsbuild at build-time without adding it as a dependency:
     - Update netlify.toml or the build.command to: npx rsbuild build
   - Better is to add the package to package.json so builds are reproducible.

4. Validate locally before pushing
   - Run locally: npm ci && npm run build
   - Ensure the same command succeeds locally before pushing to Netlify.

5. Optional: Address Node engine warnings if needed
   - Your logs include an engine warning for @semantic-release/npm requiring a newer Node version ([lines 19–22](#L19-L22)). If you need to change the Node version used by Netlify, follow Netlify's docs: https://docs.netlify.com/configure-builds/manage-dependencies/#node-js-and-javascript

Notes
- The immediate blocker is "rsbuild: not found" ([lines 79–81](#L79-L81)). Adding rsbuild to package.json (devDependencies) and committing will resolve it in most cases.
